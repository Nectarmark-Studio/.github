# Nectarmark Studio · .github

This repo sets up the [Nectarmark-Studio](https://github.com/Nectarmark-Studio) organization on GitHub:

- `profile/README.md` is the organization's public landing page.
- `SECURITY.md` is the default security policy for every repository in the organization.
